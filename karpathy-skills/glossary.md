## 슬라이드/스크립트에 쓰지 않는 한국어 표현 (번역 시 충돌)

번역 단계에서 시간을 빨아먹는 표현들. 한국어 마스터(`slides.ko.md`) 작성 시점에 미리 피한다.

- **"박제하다"** — 일본어에 1:1 대응 없음. 본문에서는 「残す」「形にする」로 의역하므로, 한국어에서도 처음부터 "남기다 / 형태로 만들다" 정도로 풀어 쓰면 번역 시 흔들림 없음.
- **"삽질"** — 비격식. 일본어로 옮기면 「無駄な作業」 등이 되는데 톤이 크게 달라진다. 본문에서는 "헛수고 / 비효율" 정도로.
- **"꾸역꾸역"** — 의태어. 일본어로 옮기는 순간 톤이 바뀐다(「なんとか」 등). 사용 회피.
- **"갈아 넣는다"** — 한국 직장 슬랭, 부정적 뉘앙스. 발표 분위기와 맞지 않음.
- **사자성어 일반** — 일본어 한자어와 형태가 같아 보여도 의미·용법이 다른 경우가 많음 (예: "역지사지" → 일본어에선 사실상 사어). 평이한 풀이로 대체.
- **"우리 회사"** — 익명화 방침 위배. "ある組織 / どの組織でも / 多くの会社で" 로 대체.
- **한국 한정 비유** — "병풍 같다", "고춧가루를 뿌리다" 등. 일본 청중이 이미지를 떠올릴 수 없음.
- **"눈치"** — 일본어 「空気を読む」와 뉘앙스가 살짝 다름. 굳이 쓸 거면 슬라이드 본문이 아닌 구두 설명에서만.
- **"가성비"** — 「コスパ」로 통하지만 회사 발표 톤에서는 「費用対効果」가 더 안전. 본문에선 회피.

## 어조 메모

- 「です・ます」 기본. 슬라이드 bullet은 명사형 / 連体形으로 단축 OK (예: "時間を短縮します" → "時間を短縮").
- 친근감 ≥ 격식. 「ご紹介します」 보다 「お話しします」를 우선. 「〜させていただきます」 남발 금지 (한 발표에 0~1회면 충분).
- 외래어 약어는 슬라이드 1장당 1~2개로 제한. CLAUDE.md / Skills / Subagents / MCP / Hooks 등 원문 유지 항목은 별도 카운트하지 않음.
- 부정적 단정 회피: "X はダメです" → "X は難しいです / 課題があります" 정도로 톤 조절.
- 숫자(정량 표현)는 사용하지 않음. "30% 短縮" 대신 "短縮される / 早くなる" 같은 정성 표현으로.
  - **단, 본 Karpathy 4원칙 LT는 예외.** A/B 정량 비교가 핵심이므로 슬라이드의 모든 숫자/표는 원문대로 일본어에서도 유지.

### B-4. 인용구 유지 정책

- 영어 원문 인용("Every changed line..." / "If you write 200 lines...")은 일본어 슬라이드에서도 **영어 그대로 유지**. 그 아래에 일본어 의역을 한 줄로 부기.
