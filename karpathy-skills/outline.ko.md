## Section 2 — 카파시 핵심 인용구 후보

원문 (`karpathy-claude.md`) 기반 발화 가능 표현:

1. **"모델들은 검증 없이 잘못된 가정을 진행한다"**
   → 원문: "State your assumptions explicitly. If uncertain, ask."
   → 한국어 의역 (슬라이드 용): "가정이 있으면 묻고 확인한다"

2. **"변경 범위를 이해하지 못한 채 코드를 부수적으로 건드린다"**
   → 원문: "Every changed line should trace directly to the user's request."
   → 한국어 의역: "바꾼 모든 줄은 요청에서 직접 추적 가능해야 한다"

3. **"200줄로 쓰고 50줄로 될 수 있다면 다시 써야 한다"**
   → 원문: "If you write 200 lines and it could be 50, rewrite it."
   → 그대로 슬라이드에 인용 가능 (강렬한 한 문장)

**최종 선정 (Slide 3):** 인용구 2와 3. 각각 사고/단순성 원칙을 대표하며 한 문장으로 충격이 있음.

## Section 3 — Slide 4 (효과 먼저) 시각화 설계

**선택:** 비교 표 (표 형식이 diff 스크린샷보다 슬라이드에서 읽기 쉬움)

```
| | A (미적용) | B (적용) |
|---|---|---|
| 변경된 파일 | N | 1 |
| diff +/- 줄 | +N / -N | +1 / -1 |
| 명세 외 변경 | N건 | 0건 |
```

숫자(N)는 `results.md` hero case 수치로 교체. 표 아래 한 줄: "같은 프롬프트·같은 모델. 차이는 CLAUDE.md 한 장."
